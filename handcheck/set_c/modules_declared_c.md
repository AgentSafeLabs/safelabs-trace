# Set C: modules declared before any tool in them was looked at

Declared 2026-10-05, before `build_items_c.py` was written or run and before any tool definition in these modules was opened (only directory listings of `site-packages` were read to choose them). Whole modules; every public tool they define is included, and none is dropped or chosen because of what the severity tagger says (the tagger is not run on set C at all). Paths are relative to the venv's `site-packages` (`safelabs-eval/.venv/lib/python3.12/site-packages`).

Not used again: everything set A used (spanner, bigtable, pubsub, exit_loop, get_user_choice, load_web_page, transfer_to_agent, bash, semantic-kernel http / math / text / time / web-search / text-memory / sessions-python plugins, openai-agents hosted tools in `agents/tool.py`) and everything set B used (ADK bigquery tools, load_memory, load_artifacts, data_agent, environment tools; ag2 messageplatform, shell, apply_patch, duckduckgo, tavily, wikipedia, perplexity, deep_research, quick_research, google_search, tinyfish, crawl4ai; crewai ask_question, delegate_work, read_file, add_image, memory tools, cache tools; semantic-kernel conversation_summary and crew_ai_enterprise; the inert kit's earlier argument sets).

1. ag2 0.14.0 (the `autogen` package), class-style tools: every Python file under `autogen/tools/experimental/google/drive/`, plus `autogen/tools/experimental/reliable/reliable.py` and `autogen/tools/experimental/browser_use/browser_use.py`.
2. openai-agents 0.18.0, sandbox capability tools: `agents/sandbox/capabilities/shell.py`, `filesystem.py`, `memory.py`, `skills.py`, every Python file under `agents/sandbox/capabilities/tools/`, and `agents/sandbox/apply_patch.py`; the Codex tool under `agents/extensions/experimental/codex/`.
3. google-adk 2.9.0, class-style and function-style tools: `google/adk/tools/skill_toolset.py`, `url_context_tool.py`, `google_maps_grounding_tool.py`, `vertex_ai_load_profiles_tool.py`, `set_model_response_tool.py`, `example_tool.py`, `preload_memory_tool.py`, `long_running_tool.py`, and `google/adk/tools/retrieval/files_retrieval.py`, `vertex_ai_rag_retrieval.py`, `llama_index_retrieval.py`.
4. semantic-kernel 1.44.1, kernel functions: `semantic_kernel/core_plugins/wait_plugin.py`.
5. llama-index-core: `llama_index/core/tools/retriever_tool.py`, `query_engine.py`, `query_plan.py`, `ondemand_loader_tool.py`, and every Python file under `llama_index/core/tools/tool_spec/`.
6. Inert catalogue: `safelabs_trace/inert_tools.py` (the `InertToolKit`), new argument sets only, at most 25 of the final 100.
7. Synthetic (written for this check): new argument-dependent variant groups, and new obscure-name tools whose description states what they do. Harmless, `example.com` and `example-*` placeholders only.

Extraction is by syntax tree, never by importing the packages, with three patterns fixed in advance: public functions with docstrings; `kernel_function` methods; classes whose `name` and `description` are string constants in the class body or in a call inside the class. A tool whose name or description is not a string constant is skipped and counted.

Stop rule: if fewer than 50 distinct external tools remain after excluding sets A and B (tool name + arguments pairs and variant groups), the build does not relax the quota silently: it builds what the modules give, says so in `report.md`, and flags that the composition target of at least 50% external is not met. Arguments for external tools are written from each tool's own parameter list with `example` placeholders; where a tool's parameters allow several actions (a command, a method, a mode), the variants are written before anything about severity is considered, and the label class of an item is never used to select it.
