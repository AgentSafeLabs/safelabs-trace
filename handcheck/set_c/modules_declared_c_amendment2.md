# Amendment 2 to modules_declared_c.md (2026-10-05, written before any fallback module was extracted)

After amendment 1 the fixed syntax patterns still give only **3 genuine external tools** (`download_file`, `browser_use`, `wait`) plus three built-in ADK tools with no description of their own. The 22 skipped classes are in modules declared in `modules_declared_c.md` ("whole modules, every public tool"), so their name and description are now read by hand from the class body (the patterns were a convenience; the declaration is the module list). Two further changes, decided from the yield, never from severity:

1. **Hand extraction of the skipped classes** in the declared modules: ag2 Google Drive toolkit and `ReliableTool`; openai-agents `ExecCommandTool`, `WriteStdinTool`, `ViewImageTool`, `SandboxApplyPatchTool` and the tools defined in `capabilities/{shell,filesystem,memory,skills}.py`; ADK `ListSkillsTool`, `SearchSkillsTool`, `LoadSkillTool`, `LoadSkillResourceTool`, `RunSkillScriptTool`, `VertexAiLoadProfilesTool`, `VertexAiRagRetrieval`, `LlamaIndexRetrieval`; llama-index `RetrieverTool`, `QueryEngineTool`, `QueryPlanTool`, `OnDemandLoaderTool`. Wrapper or plumbing classes with no description of their own (`SetModelResponseTool`, `LongRunningFunctionTool`, `SkillToolset`, `ExampleToolConfig`) are not tools an agent calls and are left out.
2. **Fallback pool: the modules of sets A and B, with new arguments only.** The brief prefers modules not used before; it forbids reusing a tool-plus-arguments pair or a variant group, not a module. Because the new modules give far fewer than the 13 distinct source files that 50 external items need under the family cap of 4, external items are first drawn from the declared new modules (every tool of them is used), then from the A/B modules, always with argument sets that appear in neither set's items or pool (checked by code). The A/B module lists are those printed in `1b_handcheck_b/modules_declared.md` and its description of set A. Everything extracted from them is pooled; selection among the pooled items follows the composition targets only (reading the item text for reader / reversible / irreversible balance, family cap 4, the argument-dependence and obscure-name quotas), never a tagger.

Stop rule unchanged: if the 50% external target still cannot be met, the build says so in `report.md`.
